## User stories

- As a guest i want to be able to see avaliable listings near me so that i can easily choose what i want
- As a host i want to be able to list my airbnb on the platform so that guest can see it and book it
- As an admin i want to be able to review host listings before they become public so that the system only contains legit spaces
- As a guest i want to be able to filter airbnb based on availible dates and amenities so that i can find the perfect listing for mr
- As a host i want to have a dashboard that shows me the details of each of my listing so that i can know how each of my listings are doing
